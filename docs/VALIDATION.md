# 공유판 검증 범위

2026-10-16 기준, 독립 설치용 소스 검증 기록입니다.

- 단위 테스트 29건 통과: URL/SSRF, 로그인, 데이터 집계, 출처/인용, OAuth 암호화·PKCE 및 설치별 APP_URL 검증.
- Next.js production build 및 TypeScript 검사 통과. 테스트용 공개 환경변수를 사용했으며 실제 회사 프로젝트에 연결하지 않음.
- 임시 로컬 PostgreSQL에 마이그레이션 001~008을 처음부터 적용해 통과.
- 초기 브랜드·회원 0건, 등록 회원 브랜드 생성·조회 성공, 비회원 조회 0건, 자기 회원 등록 거절, 토큰 테이블 접근권한 없음 확인.
- 소스에서 회사별 로그인 별칭, 회사 도메인, Google/Vercel/Supabase 운영 식별자, 브랜드 seed와 운영 조사 문서 제외.
- 공개판은 새 Git 이력이며 원본 운영 저장소의 커밋·원격 연결·환경변수를 포함하지 않음.

독립 설치를 위한 검증이며 신규 사용자의 Supabase/Gateway/Google 계정이나 운영 배포를 생성한 것은 아닙니다. 실제 로그인·Google 승인·AI 호출·방문 수신·예약 실행은 각 설치에서 SETUP.md 완료 절차로 확인해야 합니다. 해당 설치의 브라우저 검증과 실제 데이터 수신은 아직 미검증입니다.

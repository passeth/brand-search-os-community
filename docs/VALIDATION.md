# 공유판 검증 범위

2026-10-16 기준, 독립 설치용 소스 검증 기록입니다.

- 단위 테스트 33건 통과: URL/SSRF, 로그인, 데이터 집계, 출처/인용, OAuth 암호화·PKCE 및 설치별 APP_URL 검증.
- Next.js production build 및 TypeScript 검사 통과. 환경변수 없는 상태에서 첫 설치 안내 화면을 빌드하며 실제 회사 프로젝트에 연결하지 않음.
- 임시 로컬 PostgreSQL에 마이그레이션 001~008을 처음부터 적용해 통과.
- 초기 브랜드·회원 0건, 등록 회원 브랜드 생성·조회 성공, 비회원 조회 0건, 자기 회원 등록 거절, 토큰 테이블 접근권한 없음 확인.
- 소스에서 회사별 로그인 별칭, 회사 도메인, Google/Vercel/Supabase 운영 식별자, 브랜드 seed와 운영 조사 문서 제외.
- 공개판은 새 Git 이력이며 원본 운영 저장소의 커밋·원격 연결·환경변수를 포함하지 않음.

독립 설치를 위한 검증이며 신규 사용자의 Supabase/Gateway/Google 계정이나 운영 배포를 생성한 것은 아닙니다. 실제 로그인·Google 승인·AI 호출·방문 수신·예약 실행은 각 설치에서 SETUP.md 완료 절차로 확인해야 합니다. 해당 설치의 브라우저 검증과 실제 데이터 수신은 아직 미검증입니다.

## 최초 사용자 설치 점검과 보완

- 재현한 오류: 환경변수가 없는 상태의 production build가 Supabase 클라이언트 초기화 중 실패. 설정 검사 후에만 클라이언트를 만들도록 변경하고 첫 설치 안내 화면을 추가함.
- 예시 값/누락/secret·service_role 키를 공개 설정으로 잘못 사용한 경우 점검 명령이 실패하고 안내함. 계정 접근권한 검사는 별도임.
- `setup:secrets`로 빈 키만 생성, 콘솔에 원문 비밀키 미출력, 재실행 시 기존 두 키 보존을 테스트함.
- `.env.local`을 읽지 않던 Cron 해시 예시를 수정하고, Vercel production 환경을 별도 파일로 가져와 로컬 APP_URL을 덮어쓰지 않도록 안내함.
- 템플릿 비공개 사본 만들기, 저장소 clone, Node 버전, Auth 이메일 확인, 기본/AI/Google 단계 분리를 보완함.
- 별도 임시 폴더에서 의존성 설치, 예시 설정 거절, 비밀키 생성·보존, 33개 테스트, 환경변수 없는 빌드·타입 검사를 통과함. 기본 install scripts를 사용하는 새 `npm ci`도 별도로 통과함.
- 브라우저에서 설정 누락 시 첫 설치 안내와 다음 단계 링크가 표시됨을 확인함.
- 로컬 production 서버의 두 Cron API는 인증 없이 호출 시 401 반환을 확인함.

클라우드 계정 없이 진행한 검증이므로 새 사용자의 Supabase Auth 실제 로그인, Google OAuth 승인, 유료 모델 호출, GA4 수신, Vercel 원격 배포·예약 실행을 이번 점검에서 검증했다고 주장하지 않습니다. 해당 단계는 설치 후 본인 계정으로 확인해야 합니다.
